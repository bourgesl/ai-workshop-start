1. implement the issue with tests
2. when the issue leaves a decision open, ask in the slack channel at https://app.slack.com/client/T0CAU5PMZGC/C0CAX40EGN6 using the SLACK-BOT_TOKEN env variable, wait replies then go on with the implementation
2. open a PR
