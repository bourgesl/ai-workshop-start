# Skill Atlas — discover your team's agent skills

Find the agent skills your team already has, understand what they do, and open their original instructions—all from one place.

[Watch the 30-second demo](https://raw.githubusercontent.com/bourgesl/ai-workshop-start/feb457228df3c7da4571084f46091e65738881c5/docs/demo/test/demo-30s.mp4)

- **Explore repositories and organizations.** Scan a local directory, a GitHub repository, or the repositories listed for a GitHub user or organization.
- **Find skills across agent conventions.** Discover skills in the supported Agents, Claude, GitHub, and agent skill folders. Duplicate names within a repository appear once, with their other locations listed.
- **Browse and filter instantly.** See names and descriptions, narrow a repository's results as you type, and read the original skill instructions in the web view.
- **Go straight to the source.** GitHub skill links point to the scanned commit, so you can inspect the exact version you discovered.
- **Keep useful results visible.** Organization summaries show repository and skill counts, while clearly identifying failed scans and warnings.
- **Choose your workflow.** Use the command line or local web view. GitHub scans use the API without cloning repositories.

Try `./skill-atlas scan <GitHub URL | directory>` in your terminal, or run `./skill-atlas serve` to explore in your browser.
